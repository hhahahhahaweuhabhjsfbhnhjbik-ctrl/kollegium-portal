Подключим рабочее место

Участники используют свои EXE, а обращения, тесты и профили хранятся на одном общем сервере.

Как использовать это приложение?

Для сотрудников из интернета нужен защищённый HTTPS-адрес. Адрес 127.0.0.1 доступен только на этом ПК.

Настройте HTTPS reverse proxy или туннель к 127.0.0.1:3000. Закройте другой сервер портала перед запуском этого режима.

Это первая база. Создайте учётную запись ГКА — пароль будет сохранён только в виде криптографического хеша.

Папка данных:

Discord Client ID, Client Secret, токен бота и webhook добавляются в локальный файл . Можно задать названия категорий и webhook статуса. Callback выше добавьте в Discord Developer Portal → OAuth2 → Redirects. Не отправляйте файл никому; после изменения перезапустите EXE.

Данные сервера и база SQLite сохраняются локально на ПК ГКА.
